## Detailed Conceptual Modules (A–L)

## Supporting product and integrity tests

- `test_summary`: summary sentences must come directly from the source text; headline-only input produces an insufficient-text notice.
- `test_deduplication`, `test_split_integrity`: conflicting labels and repeated normalized headlines cannot cross retained splits. Raw/prepared data must be recreated to rerun the full leakage audit.
- `test_provider_normalization`: duplicate URL/headline removal, safe URLs, missing dates and first-seen date semantics.
- `test_offline_filtering`, `test_provider_outage`, `test_provider_query_and_cache`: real filters, explicit offline mode, failure handling and provider query/cache behaviour.
- `test_request_validation`, `test_dates_and_language_validation`: invalid languages, oversized/invalid shapes and date ranges fail clearly.
- `test_sentiment_and_emotion`, `test_opinion_mining`: validates positive/negative polarity compound bounds, emotion dominance, and topic opinion clustering.
- `test_embedding_classification`: validates POS-tagged word extraction, Word2Vec vector averaging, and category cosine similarities.
- `tests/frontend.test.mjs`: bookmark mutation, corrupted storage, unsafe URL rejection and article-cache merging.
- `tests/e2e/app.spec.ts`: reader navigation, persistence after reload, saving/removing, comparison, search empty state, language filters, exact text handoff into the lab, actual algorithm execution, metrics, mapping, mobile overflow and provider-outage presentation.

## Scope boundary

No RNN/LSTM, Transformer training, LDA (LSI / TruncatedSVD is implemented for topic modeling), multilingual sentence embedding, Indic POS/NER or translation model is claimed here. The n-gram demonstration is a separate small user-supplied corpus exercise, not the trained news-category classifier. Word2Vec nearest-neighbour results and centroid classification are genuine trained demonstrations, not an independently benchmarked semantic-similarity model.
